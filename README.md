PROPELHOMES WEBSITE — QUICK START

Files:
- index.html: main website
- styles.css: responsive styling
- script.js: mobile menu and demo contact form
- assets/propelhomes-logo.svg: scalable logo
- assets/favicon.svg: browser icon
- assets/homepage-concept.png: visual homepage concept

PREVIEW:
Open index.html in a browser. The hero/property images use external Unsplash image URLs, so internet access is needed for those images. Google Fonts also load online.

BEFORE PUBLISHING:
1. Replace REPLACE-WITH-YOUR-EMAIL@example.com in script.js with your real business email.
2. Update the contact details and business identity in index.html.
3. Verify the name PropelHomes is available and not confusingly similar to an existing business/trade mark before committing to it.
4. The enquiry form currently opens the visitor's email app; it is not a hosted form handler.
5. The property marketing prices are proposed introductory prices. Review them before launch.
6. Get written permission for property photographs and listing details.
7. Check legal/regulatory requirements before charging for referrals or handling buyer/tenant leads.
8. Publish the folder to a static host such as GitHub Pages or Netlify. This ZIP does not publish the website for you.

No real property listings or verified client results are claimed on this demo site.
